## 1. 배경 / 문제
Notion이나 Linear 같은 외부 SaaS에 의존하지 않고, NilPop 자체적으로 프로젝트 기획 / 이슈 / TODO / 간트차트를 관리하고 싶음. AI 개발팀 혹은 SW 개발사가 실제 운용하듯이 쓸 수 있는 수준의 도구가 필요.

Mora Knode 기획서에서 영감을 받아, 복잡한 매트릭스 조직 구조를 수용하고 계획과 실행 사이의 '리듬'을 분석하여 조직의 예측력을 높이는 방향으로 개선. "Don't Check, Just Sync" 철학을 적용하여 감시가 아닌 동기화를 강조. 초기엔 1인 사용이지만, 최종적으로 AI 에이전트들이 다양한 롤(예: PM, 개발자, QA)을 맡아 테스트할 수 있도록 매트릭스 조직/리소스 기반 설계.

## 2. 대상 사용자
- 1차 타겟: NilPop 오너 (ysh) + AI 에이전트들 (PM, 개발자, QA 등 롤로 분리된 가상 사용자). 여러 에이전트가 협업 시뮬레이션.
- 2차 타겟: 미래 NilPop 팀원 또는 외부 판매 시 소규모 SW 개발팀 (매트릭스 조직 지원).

## 3. 목표 / 성공 지표
- 1주 안에 프로젝트 / 태스크 / 마일스톤 CRUD + 간트 뷰 + 매트릭스 리소스 매니저 완성.
- AI 에이전트들 (PM, 개발자, QA 롤)을 생성하여 2주 이상 협업 시뮬레이션 운용. 최소 5개 프로젝트/50개 태스크 관리.
- 성공 지표: 매트릭스 조직 시뮬레이션으로 리소스 충돌 감소 (주관적 측정). 본인 사용 + AI 테스트 통합.

## 4. 범위
### In-scope
- 프로젝트 / 태스크 / 마일스톤 CRUD.
- 3단계 타임라인 시스템 (L1 Origin, L2 Current, L3 Real) - Mora Knode에서 영감.
- 전방위 일정 로깅 (변경 시 기록).
- 간트차트 뷰 (기본 바 렌더링).
- 매트릭스 리소스 매니저: 통합 로드 뷰 (여러 프로젝트 가동률 합산), 에너지 경보 (100% 초과 시 경고).
- AI 에이전트 롤 지원: PM, 개발자, QA 등 가상 사용자 생성 및 협업 시뮬레이션.

### Out-of-scope (이번엔 안 함)
- self-hosted + 라이선스 인증 (MVP 후 배포 단계에서 추가).
- 성과 분석 / 점수 산출 (MVP 후 추가).
- SaaS 멀티 테넌시 (온프레미스 우선).
- AI MCP 연동 (숙달 후 추가; 기본 CRUD 우선).

## 6. 기술 스택 후보
- FE: Dart / Flutter (선언적 UI로 AI 에이전트 효율성 극대화).
- BE: C# ASP.NET Core (우선) / Dart Shelf (대안).
- DB: MongoDB (JSON 기반 유연성).
- 배포: Docker Compose (MVP 이후 추후 추가).
- 인증/라이선스: self-hosted + license-client (ops/licensing 참고, MVP 후 추가).
